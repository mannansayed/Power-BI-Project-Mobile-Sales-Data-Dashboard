# 📱 Mobile Sales Data Dashboard | Power BI & Business Intelligence

## 📌 Project Overview

The Mobile Sales Data Dashboard is an interactive business intelligence project developed using Microsoft Power BI to analyze mobile phone sales and transaction data across various cities in India.

The dashboard provides insights into total sales, transactions, units sold, customer ratings, payment methods, sales trends, and brand-wise performance.

It helps businesses understand sales performance, identify customer preferences, and make data-driven decisions through interactive visualizations and reporting.

## 🚀 Key Features

- **Sales Performance:** Track total sales, transactions, and units sold.
- **Dynamic Filters:** Filter data by month, mobile model, and payment method.
- **Customer Ratings:** Analyze customer satisfaction and rating distribution.
- **Payment Analysis:** Visualize payment methods such as Credit Card, UPI, Cash, and Debit Card.
- **Sales Trends:** Analyze daily and monthly sales performance.
- **Geographical Analysis:** Interactive map displaying city-wise sales across India.
- **Brand Analysis:** Compare sales performance across mobile brands.
- **Model Analysis:** Identify top-performing mobile models.
- **Interactive Dashboard:** Explore business insights using Power BI slicers and visualizations.

2. Which mobile models are most popular?
3. Which Indian cities contribute the most revenue?
